# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within 4K Wallpaper Harvester, please report it privately.

* Do **NOT** open a public issue on GitHub.
* Please reach out via GitHub Security Advisories or contact the repository owner (`0x1998e40`) directly.
* All reports will be reviewed and addressed promptly.
